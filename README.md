# Image to ASCII

A simple React app that converts images into **ASCII art**. Upload an image, and watch it transform into a cool text-based version!

---

## Features

- Upload any image (PNG, JPG, JPEG)
- Converts the image to ASCII in real-time
- Clean and minimal React interface
- Production-ready build for easy deployment
